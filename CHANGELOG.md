# Changelog

## [1.0.0]

### Added
- Next.js 14 App Router template with strict TypeScript and Tailwind CSS
- Routes: home, about, work, work/[slug], experience, blog, blog/[slug], contact, style-guide, customization, 404, sitemap, robots
- Light and dark themes (`next-themes`, no flash on load)
- Three presets (Editorial, Minimal, Technical) and four hero layouts
- Central configuration (`src/config/*`) and typed content files (`src/content/*`)
- Command palette (`Ctrl/⌘ K`) with page, project and article search and a copy-email action
- Project filtering by category and technology with keyword search and empty state
- Blog with search, category filter, related articles, share links and previous/next navigation
- Contact form with validation, honeypot, rate limit and a honest mailto fallback
- SEO metadata, canonical URL resolution, JSON-LD
- Self-hosted variable fonts (no Google Fonts dependency)
- Language/direction foundation for English, Urdu and Arabic
- Documentation set
